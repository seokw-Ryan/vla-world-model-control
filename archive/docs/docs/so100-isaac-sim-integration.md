# SO-100 Robot Arm in Isaac Sim

Integration plan for replacing the Franka Panda with the HuggingFace LeRobot SO-100 arm in Isaac Sim.

## Robot Comparison

| | Franka Panda | SO-100 |
|---|---|---|
| **DOF** | 7 arm + 2 gripper | 5 arm + 1 gripper |
| **Control** | IK solver | Joint position control |
| **Servos** | — | 6x Feetech STS3215 |
| **Joints** | 7 revolute + 2 prismatic gripper | base rotation, shoulder, elbow, wrist pitch, wrist roll, gripper |
| **Encoder** | — | 12-bit magnetic per joint |
| **Structure** | Metal industrial arm | 3D-printed (PLA/resin) |

## URDF Source

Official repo: [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100)

- `URDF/lerobot_so100.urdf` (new calibration — zero at mid-range)
- `URDF/lerobot_so100_old_calibration.urdf` (legacy — zero at extended position)
- `Simulation/SO100/so100.urdf` (simulation-ready)

## Steps

### 1. Get the URDF

```bash
git clone https://github.com/TheRobotStudio/SO-ARM100 /tmp/SO-ARM100
cp -r /tmp/SO-ARM100/URDF assets/so100/
```

### 2. Convert URDF to USD

```bash
$ISAACSIM/python.sh scripts/convert_so100_urdf.py
```

Output: `assets/so100/so100.usd`

### 3. Run SO-100 in Isaac Sim

**Standalone VLA control:**

```bash
$ISAACSIM/python.sh sim/isaac/standalone_so100.py --instruction "pick up the red cube"
```

**Collect demonstrations:**

```bash
$ISAACSIM/python.sh scripts/collect_so100_data.py \
    --repo_id myuser/so100_pick_cube \
    --num_episodes 50 --headless
```

**Train (regular Python, no Isaac Sim needed):**

```bash
lerobot-train \
    --policy.type=act \
    --dataset.repo_id=myuser/so100_pick_cube \
    --dataset.root=./datasets/myuser_so100_pick_cube \
    --output_dir=outputs/train/act_so100
```

**Evaluate:**

```bash
$ISAACSIM/python.sh scripts/eval_so100_policy.py \
    --policy_path outputs/train/act_so100/checkpoints/last/pretrained_model \
    --num_episodes 50 --headless
```

### File Structure

```
assets/so100/
  so100.urdf                    # URDF from TheRobotStudio/SO-ARM100
  so100.usd                     # Converted USD (generated by convert script)
  assets/                       # STL mesh files
sim/isaac/
  standalone_so100.py           # Standalone VLA + SO-100 control loop
  so100_gym_wrapper.py          # Gymnasium env for LeRobot integration
scripts/
  convert_so100_urdf.py         # URDF → USD converter
  collect_so100_data.py         # Data collection with scripted policy
  eval_so100_policy.py          # Trained policy evaluation
configs/sim/
  so100_standalone.yaml         # SO-100 scene config
```

### 4. Action Space (6D)

| Index | Joint | Range |
|-------|-------|-------|
| 0 | Base rotation | continuous |
| 1 | Shoulder pitch | continuous |
| 2 | Elbow pitch | continuous |
| 3 | Wrist pitch | continuous |
| 4 | Wrist roll | continuous |
| 5 | Gripper open/close | binary or continuous |

Control is direct joint position (no IK needed).
